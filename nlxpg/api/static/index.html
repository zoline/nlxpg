외부 API(Claude)입니다. 올린 문서 내용이 Anthropic으로 전송됩니다. 사내 문서는 쓸 수 없고, 공개 문서·테스트 문서에만 씁니다(ADR-0008).
사내 문서는 원문·추출 결과·근거가 시스템 DB와 서버 디스크(data/private/)에 남습니다. 원문과 같은 등급으로 관리해야 하고, 현재 UI에는 로그인이 없습니다.
공통표준
행정안전부 공공데이터 공통표준(용어·단어·도메인)입니다. 설계 때 물리명·도메인·타입을 정하는 기준이며(ADR-0005), 판은 입니다.

한 줄에 하나씩(또는 쉼표로) 논리명을 넣으면 설계 때와 같은 규칙으로 물리명·도메인·타입을 정합니다.

공통표준도메인 전체입니다. 용어의 마지막 단어(형식단어)가 도메인 분류를 정하고, 분류 안에서 길이에 맞는 도메인을 고릅니다. nlxpg 타입은 설계에 실제로 쓰는 PostgreSQL 타입이며, 날짜·일시는 ADR-0005에 따라 공통표준과 다릅니다. ★는 길이를 모를 때 쓰는 기본 도메인(그 분류에서 용어가 가장 많이 쓰는 것)입니다.

표준 검증
기존 스키마의 컬럼을 공통표준과 비교합니다. 컬럼 한글명(COMMENT)이 있으면 한글명으로, 없으면 영문명(약어)으로 표준용어를 찾아 영문명·타입·길이를 대조합니다. 매뉴얼 [표 Ⅲ-2] 비표준 데이터 매핑정보 형식입니다.
샌드박스 스키마에서 실행해 카탈로그로 읽고 롤백합니다. 스키마를 명시한 DDL(public.x)은 인식하지 못합니다.

카탈로그(컬럼·타입·COMMENT)만 읽습니다. 접속 문자열은 저장하지 않습니다.

정규형 검사
설계된 스키마를 데이터 없이 이름(공통표준 단어 분해)·FK 관계·값 예시로 검사합니다. pgxnl Design Lab과 달리 데이터로 함수 종속을 확인하지 않으므로, "확인 필요"는 의도적인 중복일 수 있습니다.

모델 설정
LLM 접속 정보를 프로필로 등록하고, 역할마다 쓸 프로필을 고릅니다. 설정은 시스템 DB에만 저장되며 키·비밀번호는 암호화됩니다(.env의 LLM 설정은 쓰지 않습니다).

역할
프로필
프로필 추가
외부 API입니다. 문서 내용이 Anthropic으로 전송됩니다. 그래서 문서 추출(기본) 역할에는 지정할 수 없고, 새 설계에서 사내 문서가 아닐 때만 골라 쓸 수 있습니다(ADR-0008). temperature와 구조화 출력 설정은 쓰지 않습니다(항상 json_schema). 역할의 "생각 끄기"는 effort=low로 바뀝니다.

시스템 정보
현재 서버 상태입니다. LLM은 모델 설정(시스템 DB)에, 시스템 DB 접속과 암호화 키는 서버의 .env에 있습니다. 비밀값은 이 화면에 나오지 않습니다.
